
# GeoPulse Dataset Planning

## 1. Project Overview
GeoPulse is a Hyper-Local Retail Mobility Analytics project that studies customer footfall, retail activity and location-based movement patterns.

## 2. Project Objectives
- Identify high-footfall retail locations.
- Analyse customer visiting patterns.
- Identify peak shopping hours.
- Compare retail activity across locations.
- Analyse transactions and revenue.
- Generate useful business insights.

## 3. Dataset Requirements

The dataset will contain aggregated hourly observations from different retail locations.

## 4. Planned Dataset Columns

| Column | Description |
|---|---|
| date | Observation date |
| time | Observation time |
| location_id | Unique location identifier |
| location_name | Retail area name |
| latitude | Geographic latitude |
| longitude | Geographic longitude |
| footfall | Number of visitors |
| store_category | Retail business category |
| transactions | Number of purchases |
| revenue | Total sales revenue |
| weather | Weather condition |

## 5. Data Source
The initial dataset will be synthetically generated using Python.
